# v2.1.1 — Open Library (patch)

A small patch that completes a v2.1.0 feature which shipped without its UI control.

## Fixed

- **Audiobook-counting policy is now adjustable in the admin UI.** v2.1.0 added the setting that decides whether an audiobook play credits your **Book** badges, **Music** badges, or **both** — but the control was missing from the admin page, so it was stuck at the default (Books only) unless you hand-edited `PluginConfiguration.xml`. There's now an **"Audiobook plays count toward:"** dropdown in **Feature Controls** (Books only / Music only / Both), wired to load + save, and localized across all 8 languages.

## Notes

- Pure music tracks always count as Music; ebooks always count as Books — the policy only governs audiobooks (which Jellyfin files as `Audio` with book metadata).
- Documentation (README) was also reorganized around the v2.1.0 "Open Library" feature set.

## Upgrade

Drop-in from v2.1.0 / v2.0.x — no schema breakage, no data migration. 43/43 tests pass on .NET 9 / Jellyfin 10.11.x. Sigstore-signed + SLSA build-provenance attested.
